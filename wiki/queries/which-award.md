# 我適合申請哪一種？

先確認自己符合[[申請資格]]、不在[[不可申請身分]]名單內，再依序對照：

1. **家裡是低收入戶或中低收入戶，且前一學期 60 分以上？**
   → 申請低收入戶助學金（30,000）或中低收入戶助學金（20,000），無名額限制。記得附證明。
2. **前一學期 70 分以上？**
   → 可申請獎學金（32,000），依班級排名百分比擇優。
3. **前一學期 60 分以上？**
   → 可申請一般助學金（20,000），擇優核發，要做 24 小時[[生活服務學習]]。
4. **設籍蘭嶼鄉的雅美（達悟）族？**
   → 一般助學金無成績限制、不占名額，見 [[蘭嶼雅美族規定]]。
5. **大一上學期？**
   → 用高三上下學期平均成績審查，且大一新生至少占名額四分之一，見 [[成績單規定]]。

金額與門檻的完整表格在 [[獎助類別與金額]]。

這份指引是依作業要點整理，不是正式審查結果。能否同時申請多種、實際名額多少，請以[[原住民族學生資源中心]]說明為準。
