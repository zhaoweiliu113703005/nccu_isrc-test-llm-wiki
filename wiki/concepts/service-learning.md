# 生活服務學習

領有助學金的學生要履行生活服務學習（作業要點第八點）。要點未區分一般助學金與低收／中低收助學金，見 [[待確認事項]]。

## 內容與時數
- 協助學校校務行政事務（由[[原住民族學生資源中心]]安排），或參與部落服務（需事先申請核可）。
- 每學期 **24 小時**，填寫「原住民助學金生活服務學習績效考核表」，並在原民會獎助學金網站登錄。**通過考核才能領錢**。
- 累進未完成時數超過 **65 小時**者，不得申請當學期一般助學金。

## 可以抵免的情況
| 條件 | 抵免 |
|---|---|
| 通過中高級以上原住民族語言能力認證 | 全數減免 |
| 前一學期族語課程及格 | 每學分減 18 小時 |
| 前一學期參加族語研習並取得結業證書 | 依實際研習時數 |
| 前一學期成績達班級排名前 30% | 全數減免 |
| 參加原住民族文化講座、研習 | 依參與時數，須事先核可，不可重複抵免 |
| 前一學期考取與科系相關的中央主管機關證照 | 全數減免 |
